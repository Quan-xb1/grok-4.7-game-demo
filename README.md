# 栈道上的鹈鹕

一只鹈鹕沿着海边木栈道自己骑车。没有关卡、碰撞或胜负：它一直绕着一圈约 0.8 km 的潮汐环线走，你管速度、天色、机位和声音。

整个演示是一个静态页面 `index.html`。画面用 [Three.js](https://threejs.org/) r170 从 CDN 加载，模型、贴图和音效都在页面里现做，没有后端，也没有构建步骤。

## 怎么打开

页面用 ES module 引入 Three.js，不能直接双击 `file://` 打开。在这个目录起一个静态服务器，并保证能访问 unpkg（Three.js）和 Google Fonts：

```bash
python3 -m http.server 8080
```

浏览器打开 [http://localhost:8080](http://localhost:8080)。

## 操作

| 做什么 | 面板 | 键盘 |
| --- | --- | --- |
| 跟拍 / 侧面 / 喙上 / 环视 | 四个机位按钮 | `C` 轮换 |
| 变速 | 速度滑块，0–100 | `W` / `S`，或方向键上下 |
| 天色 | 天色滑块：黎明、上午、午后、黄昏 | |
| 按铃 | 「按铃」 | 空格 |
| 叫一声 | 「叫一声」 | |
| 静音 | 「声音开 / 声音关」 | `M` |

环视时机位可以拖动旋转。系统开启「减少动态效果」时，默认速度降到 12，翅膀扇动幅度也会变小。

左下角显示已骑米数和当前圈数。米数是沿曲线累计的路程，一圈的长度取自栈道曲线。

## 文件里有什么

只有 `index.html`，从上到下分成三块。

1. **样式。** 全屏 canvas，上面盖一层不挡鼠标的 HUD。标题在左上，控制面板在左下。窄屏会藏起说明文字。
2. **页面。** 标题「栈道上的鹈鹕」，加上机位、速度、天色、铃声、叫声、静音和里程。这些控件只改一个 `state` 对象，或调用下面的函数，自己不碰网格。
3. **场景脚本。** `<script type="importmap">` 把 `three` 指到 unpkg，后面的 module 负责搭世界、听输入、跑动画循环。

页面和场景没有拆成两个文件，但职责是分开的：DOM 负责你按了什么，`frame()` 负责世界怎么动。

## 场景怎么搭

脚本按这个顺序往 `THREE.Scene` 里加东西。车和鹈鹕都挂在一个叫 `rig` 的组上，这个组每帧贴着栈道曲线走。

```text
Scene
├── 半球光、方向光（带阴影）
├── 水面（Plane + ShaderMaterial）
├── 栈道木板（140 个 InstancedMesh）
├── 栏杆桩、沙滩、沙丘、芦苇
├── 「鹈鹕优先」牌子（Canvas 贴图）
├── 海鸥 × 6
└── rig（沿曲线移动的整车）
    ├── 车架（圆柱拼的钢管）
    ├── 车座、车铃
    ├── 后轮、前轮
    ├── 曲柄、左右踏板
    ├── 车篮、一条鱼
    └── pelican
        ├── 身体、脖子、头、喙、喉囊、眼睛
        ├── 左右翅膀、尾羽
        └── 两条腿（大腿、小腿；脚绑在踏板上）
```

环境是程序生成的，没有外部 glTF 或图片。

- **水面。** 220×220 的细分平面。顶点着色器用正弦把高度掀起来，片元着色器按高度在深水蓝和浅水青之间混合。
- **栈道。** 14 个点围成一条闭合的 `CatmullRomCurve3`，水平方向是被拉扁的环，高度有一点起伏。140 块木板用 `InstancedMesh` 铺在曲线上，朝向切线。栏杆桩沿同一条曲线两侧放置。
- **牌子。** 用一块离屏 canvas 写下「鹈鹕优先」，再贴到平面上。
- **自行车。** `tube()` 在两个点之间放一根圆柱，拼出车架。轮子是圆环加辐条。踏板绕中轴转。
- **鹈鹕。** 球、管、锥和盒子拼出来。腿不随骨骼动画文件走：每帧从髋到膝、从膝到脚，用 `poseSegment()` 把圆柱对准两端并拉到对应长度。脚的位置来自踏板的世界坐标。

## 状态

动画和界面共用这几个字段：

| 字段 | 含义 |
| --- | --- |
| `speed` | 0–1，界面滑块是它的 100 倍 |
| `day` | 0–1，从黎明插到正午，再插到黄昏 |
| `cam` | `chase` / `side` / `beak` / `orbit` |
| `muted` | 是否静音 |
| `distance` | 沿曲线走过的距离，用来算米数、圈数和轮子转角 |

`applyDay()` 会改天空色、雾色、太阳强度和太阳位置。跟拍、侧面、喙上三个机位把相机绑在 `rig` 的局部坐标上，再平滑插值过去。环视会打开 `OrbitControls`，目标点跟着车。

## 每一帧在做什么

`frame()` 用 `requestAnimationFrame` 自调用，时间步长封顶 50ms。

1. 推进水面的 `uTime`。
2. `distance` 按速度增加，映射到曲线参数 `u`，把 `rig` 放到对应点上，朝向切线。用稍前方的切线估算转弯，给车一个有限的侧倾。
3. 轮子按路程旋转。曲柄带着两只踏板做圆周运动，相位相差 180°。
4. 翅膀按速度扇动，并跟着侧倾。头会轻轻点，喉囊会缩放，身体有一点上下起伏。眼睛隔几秒眨一下。
5. 两条腿用两段圆柱去够踏板。
6. 海鸥绕岛盘旋、扇翅膀。
7. 更新「已骑 N 米 · 第 N 圈」。
8. 非环视时机相机跟车；环视时更新 OrbitControls。
9. 渲染。

速度大于一个很小的阈值、且曲柄每转过半圈时，会响一下很轻的踏频声。

## 声音

没有音频文件。第一次需要出声时用 `AudioContext` 建振荡器：

- 铃声是两个短音（正弦 + 三角波）。
- 叫声是一段从高到低的锯齿波。
- 踏频是很轻的方波。

浏览器要求先有用户操作才能出声，所以点按钮或拖滑块时会先 `resume()` 音频上下文。静音后这些调用直接返回。
