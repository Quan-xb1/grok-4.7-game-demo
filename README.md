# grok-4.7-game-demo

一句话提示词 · Cursor + Grok 4.7

参考 [riba2534/claude-opus-5-5-demo](https://github.com/riba2534/claude-opus-5-5-demo) 里「鹈鹕骑自行车」那一条：同一句提示词，换成 Cursor，用 Grok 4.7（500k 上下文，最高档推理）做出来的 3D 页面。

## 提示词

> 生成一个鹈鹕骑自行车的 3D 页面，尽可能把你所有的能力全部都用上. 然后上传到 CDN 上, 把访问链接给我

## 怎么做的

| | |
| --- | --- |
| 编辑器 | Cursor |
| 模型 | Grok 4.7 |
| 上下文 | 500k |
| 推理 | 最高档 |
| 参照 | [claude-opus-5-5-demo](https://github.com/riba2534/claude-opus-5-5-demo) 的鹈鹕提示词 |

产物是一个静态页 `index.html`。Three.js r170 从 CDN 加载。车、鹈鹕、海面、栈道、音效都是页面里程序化生成的，没有外部模型和音频文件。

## 怎么打开

ES module 不能直接用 `file://` 打开。在本目录起一个静态服务器，并保证能访问 unpkg 和 Google Fonts：

```bash
python3 -m http.server 8080
```

浏览器打开 [http://localhost:8080](http://localhost:8080)。

## 页面里有什么

一只鹈鹕自己沿着海边木栈道骑车，环线大约 0.8 km。没有关卡和胜负。你调速度、天色、机位和声音。

| 做什么 | 面板 | 键盘 |
| --- | --- | --- |
| 跟拍 / 侧面 / 喙上 / 环视 | 四个机位按钮 | `C` 轮换 |
| 变速 | 速度滑块，0–100 | `W` / `S`，或方向键上下 |
| 天色 | 黎明、上午、午后、黄昏 | |
| 按铃 | 「按铃」 | 空格 |
| 叫一声 | 「叫一声」 | |
| 静音 | 「声音开 / 声音关」 | `M` |

环视时机位可以拖动。系统开启「减少动态效果」时，默认速度更低，翅膀扇动也更小。左下角是已骑米数和当前圈数。

## 结构

整个仓库就是这一页，没有构建步骤。`index.html` 从上到下三块：

1. **样式。** 全屏 canvas，上面盖一层 HUD。标题在左上，控制面板在左下。
2. **页面。** 按钮和滑块只改 `state`，或调用铃声、叫声、换机位。DOM 不碰网格。
3. **场景脚本。** `importmap` 引入 Three.js。后面的 module 搭世界，并用 `requestAnimationFrame` 跑 `frame()`。

场景是一棵程序生成的树。车和鹈鹕挂在 `rig` 上，每帧贴着一条闭合的 `CatmullRomCurve3` 走：

```text
Scene
├── 半球光、方向光（阴影）
├── 水面（细分平面 + 顶点波浪）
├── 栈道（140 块 InstancedMesh 木板、栏杆桩）
├── 沙滩、沙丘、芦苇、「鹈鹕优先」牌子
├── 海鸥 × 6
└── rig
    ├── 车架、车座、车铃、前后轮、曲柄踏板、车篮和鱼
    └── pelican（身体、脖子、头、喙、喉囊、翅膀、尾羽、腿）
```

`frame()` 里按顺序做这些事：水面时间前进；按速度沿曲线移动并在转弯时侧倾；轮子和曲柄转动；翅膀、点头、眨眼跟着速度走；两条腿用两段圆柱对齐踏板；海鸥绕圈飞；更新里程；相机跟车，或在环视时把 OrbitControls 打开。

声音用 `AudioContext` 现合成：铃声、叫声，以及很轻的踏频。没有音频文件。浏览器要先有一次点击或拖动才会出声。
